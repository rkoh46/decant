# Third-party notices

Decant for Windows bundles these programs and libraries unchanged, each under its own licence, in the `Tools`
folder next to `Decant.exe`. Decant runs the programs as separate processes and loads the libraries as DLLs.
Sources: libimobiledevice.org (github.com/libimobiledevice), openssl.org, msys2.org; the exact builds are listed in
`tools\mingw64\PROVENANCE.md` in the source tree.
